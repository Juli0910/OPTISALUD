¿Qué incluye el precio integrado de los sistemas?
El precio total al seleccionar procesos y sistemas incorpora la implementación técnica inicial una sola vez y el IGV. El acceso móvil es un complemento opcional que requiere un sistema empresarial seleccionado. Esto comprende la configuración común, estructura de datos y mecanismos básicos de usuarios y permisos previstos en el alcance. No se añade una partida extra al finalizar: al contratar varios sistemas, esta base se calcula una sola vez en el proyecto. En el PDF se detalla por transparencia. Hosting, licencias, servicios externos y conexiones especiales no se incluyen automáticamente.

Catálogo y precios

Los 47 conceptos y precios iniciales corresponden a las hojas 00, 01 y 02 de SIGMA (45 procesos empresariales + implementación base + acceso móvil opcional). Las ediciones administrativas son ajustes de OPTISALUD y ya no constituyen el catálogo original. Los importes editables son valores sin IGV. La edición cambia nuevas proformas de este navegador. Cada solicitud ya registrada conserva sus importes originales salvo ajuste expreso en la revisión.

Configuración de cotizaciones

El correo del administrador se utiliza para preparar un mensaje mediante su aplicación de correo. El HTML no envía correo ni archivos adjuntos automáticamente.

Transferencia y respaldo de datos

En el modo local, cada computadora guarda sus datos por separado. Exporte la configuración de precios y compártala con la persona que utilizará el perfil Cliente; importe las solicitudes JSON recibidas para su revisión.

La contraseña de administrador no se incluye en los archivos de respaldo. No envíe los archivos JSON a destinatarios no autorizados; pueden contener datos de contacto de clientes.
